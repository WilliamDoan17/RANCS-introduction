# Bitwise Operations 
My notes about Bitwise Operators 

## The core Operators

### Bitwise AND (&): 
- Compares two bits
- If both bits are 1, returns 1. Otherwise, returns 0.

| Bit 1 | Bit 2 | Result |
| --- | --- | --- |
| 0 | 0 | 0 |
| 1 | 0 | 0 |
| 0 | 1 | 0 |
| 1 | 1 | 1 |

- Example: `1100101` & `100111` = `0100101`
